# Rules for this repo

- All filter modelling is done in **Julia** (`src/`, `scripts/`). Every number that goes into a
  document, a message to the partner or the grant application comes from a Julia run.
- `python/` is a legacy mirror kept for reference only. Do not use it to produce results.
- If Julia cannot be run where you are, write the Julia script, mark results as
  "pending Julia run", and say so. Never fill in numbers from another tool.
- Measurements come from the partner's team (Fen); record the date and who measured.
